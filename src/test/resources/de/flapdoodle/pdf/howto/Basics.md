# Basics

## Hello World
              
create a document factory:

```java
${helloWorld.factory}
```

render to an output stream:

```java
${helloWorld.render}
```
![hello-world.png](${helloWorld.png})

[hello-world.pdf](${helloWorld.pdf})

## Meta Data

Add creation date and producer:

${metaData.factory}
